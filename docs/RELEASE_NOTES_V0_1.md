# RecorAndro v0.1 RC1

Proposed title: **RecorAndro v0.1 RC1 — Processing Deck**

- Run the local Processing Deck in Chrome from a foreground Termux adapter.
  Select an existing recording, check progress or resume by session ID, and
  download verified audio part ZIPs from Exports.
- Import an immutable original and produce audio part ZIPs with manifests.
  Photos are optional. Full Archive is off by default and can be requested
  separately from the audio parts.
- Redmi Note 10 Pro evidence covers a real ~61.5-minute recording, three
  verified parts, Chrome download and owner-confirmed Android Share.

The active Processing screenshot and independent receiver ZIP hash comparison
are **DEFERRED / NOT VERIFIED** for this release candidate. See the
