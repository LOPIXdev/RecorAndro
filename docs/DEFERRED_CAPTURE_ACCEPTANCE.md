# Deferred Part 3 / final-device audio capture acceptance

On the same Redmi hardware, compare the intended RecorAndro capture workflow
against Xiaomi's original Recorder application at its highest-quality setting,
under comparable recording conditions. Record actual supported device capture
formats, signal quality, repeatability, reliability, storage and thermal/runtime
measurements. Determine the highest reliably supported quality from these
measurements; higher nominal sample rate or bitrate alone does not prove better
sound. Preserve comparable source samples and listening/measurement evidence.

This is a deferred acceptance item, not Step 5.1 implementation. No recorder,
capture framework switch or frozen media-processing contract change is made.
